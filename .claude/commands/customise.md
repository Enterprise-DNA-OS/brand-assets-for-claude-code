# Make it yours

Read the schema, CLI, import guide and compliance rules. Translate the requested field, terminology or check into a numbered migration. Back up a business database first. Never edit an applied migration. Update the CLI, documents, views, import mapping and tests that use the change. Preserve default holds, scope checks, append-only history and explicit evidence. Run npm test, apply npm run migrate, query the result and return proof in this chat. Keep the database private. No media processing or sending pipeline is added by this recipe.
